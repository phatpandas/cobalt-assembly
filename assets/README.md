# Asset directory

This directory is reserved for production-ready Cobalt Assembly brand assets:

- Primary horizontal lockup SVG
- Stacked lockup SVG
- Assembly Mark SVG
- Favicon and app-icon set
- Motion mark in Lottie or React animation format
- Social, presentation, and product-launch cover masters

No visual asset files are included yet. The construction and usage standards are defined in [the visual-system document](../docs/03-visual-system.md).
