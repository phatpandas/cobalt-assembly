## Ecosystem paths

### Idea to market

`Market Lens → Market Premise → Message Foundry → Glassline Identity → Market Frame → Value Model → Release Current`

### Audience growth

`Editorial Gravity → Editorial Rail → Content Weave → Campaign Field → Metric Current → Metric Review`

### Premium service delivery

`Contract Studio → Contract Canvas → Client Gallery → Evidence Archive → Studio Ledger`

### Expertise to education

`Research Clarity → Reference Field → Learning Composer → Learning Scaffold → Commerce Frame`

### Executive operating layer

`Command Grid` connects the ecosystem, while `Week Rhythm`, `Choice Map`, and `Margin Atlas` create a durable management cadence.

Every handoff should preserve structured context, assets, decisions, and next actions—not generic AI output.
