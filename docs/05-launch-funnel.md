# Cobalt Assembly — Launch Funnel

## Funnel principle

Guide customers toward the next system they need. Do not pressure visitors through a generic catalog or discount-led sales sequence.

## Core funnel architecture

```text
Discovery
  → Precision Path Diagnostic
  → Personalized result
  → Outcome-specific email sequence
  → Entry product
  → Core template or tool
  → Account activation
  → Contextual next product
  → Cobalt Circle
```

## Lead magnet — The Precision Path Diagnostic

**Positioning:** an interactive assessment that identifies the highest-leverage system a digital business should build next.

**Headline:** Find the next system your business needs.
**Primary CTA:** Build My Precision Path.

### Experience

1. Select current business stage.
2. Choose the most pressing operating outcome.
3. Assess clarity across offer, audience, delivery, systems, and growth.
4. Enter an email to receive a tailored result.
5. Receive a personalized operating path.

### Result structure

| Result element | Purpose |
|---|---|
| Operating signal | Names the primary business constraint |
| Priority pathway | Validate, Shape, Release, Grow, Deliver, Teach, or Lead |
| Immediate action | One useful move for today |
| 30-day system map | Short sequence of practical milestones |
| Entry recommendation | One relevant content product or template |
| Next-layer recommendation | One template or tool that extends the result |

### Design rules

- White-studio page with a single cobalt orbital progress trace.
- Silver progress surfaces; cobalt identifies the active step.
- One question per screen; no dense form wall.
- Result page is an editorial composition, not a loud scorecard.
- No hidden opt-ins, fake urgency, or manipulative exit behavior.

## Email sequence — ten-day core journey

| Timing | Subject direction | Purpose | Primary CTA |
|---|---|---|---|
| Immediate | Your Precision Path is ready | Deliver the result and immediate action | Open your path |
| Day 1 | The system worth building first | Reframe the visitor’s constraint | See the recommended next step |
| Day 3 | What clarity changes | Teach the value of a connected operating system | Explore the relevant pathway |
| Day 5 | A workflow built around your outcome | Show a concrete product workflow | View the product |
| Day 7 | Turn the insight into an operating asset | Present the core product with live proof | Explore the system |
| Day 9 | What comes after the first system | Introduce the natural cross-sell path | Continue the build |
| Day 10 | Keep the signal, choose the pace | Give a respectful conversion choice | Choose your next step |

### Segmentation

| Pathway | Entry recommendation | Core continuation |
|---|---|---|
| Validate | Market Premise | Market Lens → Market Frame |
| Shape | Digital Poise | Glassline Identity → Message Foundry |
| Release | Release Strategy | Release Current → Release Choreography |
| Grow | Editorial Gravity | Editorial Rail → Content Weave |
| Deliver | Client Ritual | Contract Canvas → Contract Studio |
| Teach | Research Clarity | Learning Scaffold → Learning Composer |
| Lead | Strategic Judgment | Command Grid → Metric Current |

### Email design

- White canvas, silver dividers, cobalt links and CTAs.
- One primary message and one CTA per email.
- Large Sora headline and restrained Manrope body copy.
- No aggressive countdowns, dark banners, or last-chance theatre.
- Include preferences and an easy unsubscribe path.

## Conversion sequence

| Page | Job | Primary proof |
|---|---|---|
| Diagnostic landing page | Earn the assessment start | Clear outcome and elegant interaction |
| Result page | Create relevance | Personalized pathway and immediate action |
| Entry product page | Convert initial intent | Sample framework, workspace, or lesson |
| Core product page | Establish deeper value | Live workflow proof |
| Checkout | Remove friction | Clear access, inclusions, support terms |
| Account activation | Produce first success | Guided setup and visible next action |
| Post-purchase pathway | Expand the system | One contextual next recommendation |

## Offer ladder

| Level | Offer type | Role |
|---|---|---|
| Free | Precision Path Diagnostic | Qualify by operating need |
| Entry | $29–$59 content product | Build trust through a focused method |
| Core | $69–$149 template | Establish a practical operating workspace |
| Acceleration | $19–$39/mo tool | Speed up recurring high-value work |
| Outcome bundle | $179–$299 | Combine products for one business goal |
| Ongoing ecosystem | Cobalt Circle, $299/quarter | Curated releases and intelligence |

Use value-led bundles rather than routine discounting.

## Upsell and cross-sell logic

| Starting product | Primary upsell | Supporting cross-sell |
|---|---|---|
| Market Premise | Market Frame | Market Lens |
| Digital Poise | Command Grid | Glassline Identity |
| Release Strategy | Release Current | Release Choreography |
| Editorial Gravity | Editorial Rail | Content Weave |
| Client Ritual | Client Gallery | Contract Canvas |
| Research Clarity | Reference Field | Learning Composer |
| Any template | Relevant tool | Related content product |
| Any tool | Connected template | Cobalt Circle after activation |

Offer only one relevant post-purchase upgrade. It must solve the next obvious task and preserve customer control.

## Funnel signals

```text
Landing view
  → Diagnostic start
  → Diagnostic completion
  → Result viewed
  → Product-page visit
  → Purchase or trial
  → First-success activation
  → Next-product adoption
  → Cobalt Circle retention
```

Maintain explicit consent, clear privacy language, accessible forms, reduced-motion support, and honest product representation throughout.
